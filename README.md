# Esston Technology — Merged UI Prototype

## Run
Open `index.html` in a browser. For best compatibility, run a local static server from this folder, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`. The prototype uses some external CDN fonts/icons/Tailwind assets, so an internet connection may be needed for the original Stitch screens to render exactly.

## Integrated screens
- Splash and role selection / login
- Customer Home, My Starter, Motor Control, Set Motor Schedule, Motor Settings
- My Orders, Help & FAQ, Contact / Enquiry
- Dealer Dashboard, Dealer Product Catalogue, Dealer Enquiries, OTP Verification

## Important
This is a navigable front-end prototype, not a production app. Authentication, OTP, real SMS motor commands, live status, enquiry persistence, product data, pricing, and brochure downloads require backend/API integration and validation. Dealer enquiries and OTP page are simple prototype additions to complete the navigation flow.
